2Kimi（K3）已开源

判定依据：Hugging Face API 端点直查、LICENSE 原文直读、GitHub/HF/ModelScope 组织页直查，非媒体转述。

  • 社区 1-bit 量化落地：Unsloth 发布 Kimi-K3-GGUF，提供 UD-IQ1_S（594GB）到 UD-Q8_K_XL（1.56TB，无损）全系列量化，1-bit 版本据发布者自述保留约 78.9% 准确率，相比原始 1.56TB 权重压缩约 62%。这把自建门槛往下拉了一截，但 594GB 仍无法塞进消费级 128GB 内存的 Mac Studio，需要 SSD 卸载或多卡工作站/服务器级设备——量化落地了，但"能用"仍只对拥有高端本地设备或多卡集群的用户开放。 T1Hugging Face unsloth/Kimi-K3-GGUF 仓库
  • SGLang 官方 Cookbook 页上线：新增 Kimi-K3 页面（标注"NEW"，覆盖 8 个硬件平台，含 PD 分离、DSPARK 投机解码），但命令面板仍统一标注"Final Verification In Progress"——说明 SGLang 团队的收敛工作还在进行，尚未达到 vLLM 07-27 那篇"正式支持"文章的完成度。 T1SGLang 官方 Cookbook
  • LICENSE 原文直读确认：今日直接读取官方 LICENSE 全文，条款与此前报道一致——年营收超 2000 万美元的 MaaS 业务需单独签约；月活超 1 亿或月收入超 2000 万美元的产品需展示"Kimi K3"字样；内部使用及通过官方产品/认证伙伴访问不受约束。判读不变：防大厂转售牟利，不防中小团队自用。 T1Kimi K3 官方 LICENSE 原文
点赞/下载曲线背离：downloads 99,214（连续第三天读数完全不变），likes 8,654（较昨日 8,082 上升 572，三天来第三次上涨）。比较可能的解释是 HF API 端点对下载计数字段存在缓存延迟，而不是真实下载量停滞——但这只是推断，需要明天用渲染页面而非 API 交叉核实。 T1HF API 端点，三次抓取对比
  • 资本市场外溢效应：费城半导体指数（SOX）自 06 月末高点下跌超 20%，正式进入技术性熊市；SOXX ETF 07-29 收盘跌 5.52%。媒体普遍将诱因归为"市场对中国开源模型冲击美系算力需求预期的重新定价"，英伟达、博通、AMD、英特尔、美光均受波及；07-28 传导至亚洲，韩国 Kospi 跌近 11%，SK 海力士跌 14%，三星跌 13%。需要谨慎：把跌幅完全归因于 K3 是简化叙事，同期还叠加芯片管制、AI 资本支出预期降温等因素。 T3cryptobriefing.com、SOXX 历史价格数据
  • 中美政策公开对峙升级：中国商务部 07-27 发表声明，指责美方"AI 霸权主义"，警告"将采取一切必要措施维护自身合法权益"——这是中方首次就蒸馏指控争议作出正式政府层面回应。同期纽约时报报道（援引四名知情人士）称美方更倾向对个别模型"逐案审查"而非全面禁令，截至目前白宫和商务部均未发布正式规则或制裁清单。 T3Reuters（经多家媒体转载）、纽约时报（经 MLQ.ai 转引）
  • Anthropic 公开表态不支持全面禁令：CEO Dario Amodei 07-27 发文明确表示"从未主张禁止开放权重模型"，称不含危险能力的开放权重模型是"公共品"，但主张收紧对华芯片管制、打击"工业级蒸馏"。Anthropic 未签署 07-24 由英伟达、微软等 50 家机构联署的支持开放权重联名信，理由是不认同其"开放访问必然更利于防御方"的假设。 T1Anthropic 官方博客（经 MLQ.ai 转引原文链接）
3Qwen已承诺

官方口径未变，仍是 07-19 那条 X 帖子："Qwen3.8 is launching and going open-weight soon!"——只说"soon"，无日期无仓库。距首次承诺已满 11 天。

  • Qwen 官方研究页最新仍是 07-21 的 Qwen-Image-3.0；HF 组织页最新更新仍是 7 天前的 Qwen3-ASR 系列，模型总数 458，与前两日一致。 T1Qwen 官方研究页、HF Qwen 组织页
  • HF 论文列表（48 篇）、ModelScope（模型总数 460）均无新增。GitHub QwenLM（49 个仓库）今天活跃的是 qwen-code 与 FlashQLA，均为基础设施/工具类常规迭代，非模型新闻。 T1HF Qwen 论文列表、ModelScope、GitHub QwenLM
  • 第三方分析梳理出一条背景时间线：Qwen 最近一次真正开源的通用模型是 Qwen3.6-27B（Apache 2.0，2026-04-22），从那之后到今天已 99 天没有新的开源通用模型；同期 Qwen3.6-Max、Qwen3.7-Max、Qwen3.8-Max-Preview 三代旗舰全部闭源，形成"四连闭源"模式。此为第三方对公开时间线的整理，非官方表态，仅作背景参考。 T3digitalapplied.com 时间线整理

判读：连续三天复查五个一手信源，Qwen3.8 没有任何新增动作。Qwen 团队的工程投入仍集中在编码工具和基础设施库上，模型层面持续静默。

5态势判断

基于当天和之前几天已核实的具体数字做外推判断，不下确定性断言，供参考。

  • 点赞/下载曲线背离值得持续盯：点赞数三天连涨（7,209→8,082→8,654），下载数三天原地不动（均为 99,214）。如果明天用不同抓取路径（渲染页面而非 API）仍读到 99,214，基本可以确认是缓存问题；如果读到显著更高的数字，说明 API 端点本身有滞后（本判断基于三次连续抓取的对比，样本量有限）。
  • 半导体股抛售可能不是一次性事件：国产芯适配（海光→昇腾/摩尔线程）与半导体股抛售同步发生，市场似乎把 K3 当作结构性威胁在定价，而不只是发布当天的情绪反应。但这是间接信号推断——同期还有芯片出口管制、AI 资本支出预期降温等其他因素叠加，不能把跌幅完全归因于 K3（本判断基于媒体报道的时间相关性，非因果证据）。
  • 中美政策短期内造成实质冲击的概率可能低于舆论声量：中国商务部正式声明反击，是这场对峙从"讨论"升级到"政府对政府"的信号；但据纽约时报援引四名知情人士的报道，美方内部更倾向"逐案审查"而非全面禁令，且截至目前无正式制裁或 Entity List 落地。如果这种"表态升级、行动未跟进"的模式持续，短期内对 K3 实际可用性的冲击可能有限（本判断基于媒体转述的政策讨论方向，未见官方文件，需持续验证）。
