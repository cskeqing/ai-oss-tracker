2Kimi（K3）已开源

判定依据：Hugging Face API 端点直查 + GitHub MoonshotAI 组织页直查，非媒体转述。

  • 技术报告全文首次公开：昨天取证清单里"该查未查"的技术报告全文，今天确认已随权重同批发布，47 页，公开于 K3 官方仓库。核心技术点：KDA 与 Gated MLA 按 3:1 比例混合；Stable LatentMoE 用 SiTU-GLU 和 Quantile Balancing 在 896 选 16 的极端稀疏度下保持训练稳定；视觉编码器 MoonViT-V2 用 next-token 预测从零训练，不需要对比学习预训练。 T1Kimi K3 官方技术报告
  • MoonEP、AgentEnv 正式开源：三项训练基建里，FlashKDA 此前已开源，MoonEP（专家并行通信库）和 AgentEnv（与 kvcache-ai 联合开发的 Agent 强化学习沙箱）随本次一并公开，均可在 GitHub MoonshotAI 组织页下载。 T1GitHub MoonshotAI 组织页
  • FlashKDA 在 H20 上有官方实测数据：技术报告披露 FlashKDA 在 NVIDIA H20 上比 flash-linear-attention 基线快 1.72–2.22 倍（prefill 阶段），可直接替换为 flash-linear-attention 的后端。这是官方首次公开 H20 相关的实测数字——但这是算子层面的速度对比，不是"H20 能不能部署 K3 整机推理"的答案，vLLM/SGLang 官方部署配方目前仍不含 H20 这一档。 T1Kimi K3 官方技术报告
vLLM 官方支持文章已发布（07-27，回应昨日明日盯点）。标题《Kimi K3 Is Here: Efficient Day-0 Support on vLLM》。基线速度 118 tok/s（单用户，TP16），DSpark 投机解码后到 370 tok/s（3.14 倍提升）。这个数字比 Artificial Analysis 昨天给出的 32 tok/s 高出一个量级——差异在于 AA 测的是默认配置下的批量吞吐场景，vLLM 这个数字是单用户、开启投机解码优化后的峰值，两者统计口径不同，不能直接比较谁的数字"更准"。官方最低硬件门槛口径未变：至少 1 个 8×B300（或 GB300 NVL72）节点，16×B200 同样支持。 T2vLLM 官方博客
  • 国产芯生态扩展到三家：继海光 DCU（07-28 报道，性能损耗 12% 以内）之后，华为昇腾（Ascend 950 系列、Atlas A3，Ascend CANN 官方公告）和摩尔线程（MTT S5000，MUSA 软件栈）今天分别公告完成 K3 适配并实现稳定运行。三家的适配都是官方/合作方自己公告的结果，暂无第三方独立复现的性能数字。 T3aibase.com、futunn.com
  • 18 家美国公司连夜部署，舆论反差被放大：网友 Ding 整理的名单显示，在美国政府和 Anthropic 等公司花钱游说封锁中国开源模型的同时，至少 18 家美国公司权重开源当晚就部署商用。Cursor、Cognition（Devin 开发商）公开确认接入；Cognition 原话是"在 Frontier Code1.1 基准上，K3 是我们测试过的第一个性能接近前沿水平的开源模型"。这条只反映了部分美国科技公司的快速反应，不代表美国政府封锁政策本身发生了变化，两者是同一新闻里的不同主体。 T3aibase.com（转引网友 Ding 整理名单）、futunn.com（转引 Cognition 官方表态）
  • 阿里云同时上架 K3：阿里云 Bailian 与通义千问 API 平台均已上架 K3 模型 API，与摩尔线程超节点实例达成 Day-0 兼容——即 Qwen 的运营方阿里云，同时在卖 Kimi 的模型服务。 T3futunn.com

下载量/点赞数：downloads 99,214（与 07-28 记录一致，24 小时内未见新增，说明这个数字本身在 API 端可能有更新延迟，需要明天再核实一次），likes 8,082（较 07-28 记录的 7,209 上升 873）。Hugging Face CEO Clem Delangue 公开发帖称 K3 开源半小时内冲上平台热榜第一，"史上最快的增长速度"。 T1HF API 端点 T3futunn.com 转引 Clem Delangue 推文
