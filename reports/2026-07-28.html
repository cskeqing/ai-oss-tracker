许可证 —— 今日解决，不再是“未验证”

官方 LICENSE 原文已直接读到。核心条款：① 基础权限接近 MIT（可用、可改、可分发、可商用、可创作衍生作品），需保留版权与许可声明；② “Model as a Service”条款：若 MaaS 业务连续 12 个月内累计营收超 2000 万美元，须与 Moonshot 另行签约才能商用；③ 若衍生产品月活超 1 亿或月收入超 2000 万美元，须显著展示“Kimi K3”；④ 内部使用及经 Moonshot 官方产品/认证伙伴访问的场景不受②③约束；⑤ 不提供任何担保。
这不是 OSI 认证的开源许可证，准确说法是“开放权重，附带商用规模门槛”。媒体传的“Modified MIT”方向大致对，但没提两条商用条款，属简化转述。 T1Kimi K3 官方 LICENSE 原文 · 直接读取

生态适配 —— 落后权重发布

  • vLLM 官方博客最新一篇仍是 07-23 的《Announcing vLLM AFD Plugin》，与 K3 无关。上一篇 K3 相关文章仍是 07-22 的生产级支持预览，权重发布后 vLLM 侧还没有对应的正式支持文章，两者之间有滞后。 T2vLLM 官方博客 · 渲染抓取
  • SGLang、llama.cpp、transformers 的 K3 支持状态今天没查，见取证清单 5.3。

技术要点

2.8T 参数，KDA（Kimi Delta Attention）+ AttnRes（Attention Residuals）架构，896 个专家中激活 16 个，1M token 上下文，原生视觉多模态。API 定价三档：缓存命中输入 $0.30 / 百万 token，未命中输入 $3.00，输出 $15.00。今日 API 端点数据与官方公布的参数规模一致。

深度分析（模型进入已开源后的六项）

性能：Artificial Analysis 全球排名第四，但速度和幻觉率是两条要盯的短板。放进全榜（含闭源）看，K3 只落后三个闭源旗舰；单看开源模型，K3 排第一。价格比闭源旗舰便宜，但在开源分组里是最贵一档；速度是同分组里最慢的一个。

这说明什么：K3 不是"开源里比烂"，是真的挤进了全球前四，压过了 Grok、GLM、Gemini 这些同期在跑的模型（不管开源闭源）。价格也不是"贵"，跟 Opus/GPT 比反而便宜，"最贵"只在跟同为开源的模型比时才成立。真正的短板是速度：GLM-5.2 参数量（753B）比 K3 小得多，却能跑到 220 tok/s，说明 32 tok/s 未必是"模型太大"的物理下限，更可能是 KDA 这个新架构还没被 vLLM/SGLang 充分优化——07-25 的官方部署配方仍标"pre-release"。这个数字会不会随生态适配跟进而改善，是接下来最值得盯的一条。 T1Artificial Analysis（Kimi K3 / Claude Opus 5 / GPT-5.6 Sol / GLM-5.2 / DeepSeek V4 Pro 各页）· 渲染抓取

能否真的用起来：官方给的门槛是 8 张顶级 GPU 起步，社区量化版本已经在追。vLLM 官方 recipe 明确写着最低硬件要求是 8 张 NVIDIA GB300（单卡 288GB 显存），多节点部署才谈得上生产级流量；这不是社区博客估算的数字，是 vLLM 官方发布的部署配方原文。与此同时，社区已经有多个 GGUF 量化仓库挂出（AtomicChat/Kimi-K3-GGUF、unsloth/Kimi-K3、GrEarl/Kimi-K3-GGUF），但 GrEarl 的仓库说明里作者自己承认“没有足够算力跑通和改进这个量化版本，这是理论上的量化”——说明量化版本已经有人在做，但目前还没有一个经过充分验证、可直接稳定使用的版本。
这说明什么：K3 的“开源”目前只对拥有多卡集群的团队是真开源，对普通开发者和中小团队，实际可用路径仍是官方 API，跟没开源时的处境差别不大。社区量化是自建的希望所在，但还在早期、不成熟阶段，观察这些仓库能不能跑通、能不能被更多人验证，是判断“K3 何时对普通人真正开放”的关键信号。 T2vLLM 官方 Recipe · 渲染抓取 T3Hugging Face 社区量化仓库 · 搜索命中

外部评测与真实使用反馈

幻觉率上升Artificial Analysis

独立测出幻觉率 51%，比上一代 K2.6 的 39% 明显升高——智能分数涨的同时，编造答案的比例也涨了。官方自己没提这条，是评测挖出来的。

定价叙事反转eesel / puter.com

K2.6 约 $0.95/$4，K3 涨到 $3/$15，跟 Claude Sonnet 5 同价，涨幅 3–4 倍。Kimi 不再是"便宜的前沿模型"，社区反应最大的是这一点，不是能力。

视觉纠错实测puter.com 可复现测试

网页截图对比找 5 处故意做的 CSS 差异，K3 5/5 全找到，且没有报告不存在的差异——跟幻觉率数据形成对照：具体、有明确答案的任务表现扎实。

Token 效率存疑Hacker News 用户

多位用户反映 K3 完成同样任务比 Fable 5 耗更多 token，这直接影响实际账单，是比单价更该盯的成本变量。

“我用了几个小时，这是个很棒的模型。盲测的话我可能分不出它和 Fable 5 的区别。$100 的 Kimi Coding 套餐额度，大致相当于我用 $200 的 Anthropic 套餐主要跑 Fable 时的额度。” InsideOutSanta · Hacker News（经 eesel.ai 转引）
“Fable 5 两周前才发布，GPT-5.6 Sol 一周前才发布。K3 是比它俩差一点，但比其他所有模型都强。所以我会说落后几周，不是几个月了……” frabcus · Hacker News（经 eesel.ai 转引）

这些评价放在一起说明什么：K3 的"强"是真的，多篇独立评测方向一致；但"便宜"的叙事已经不成立了，这可能会削弱它对预算敏感的中小团队的吸引力——跟许可证设计形成一个有意思的反差：官方一边放宽许可证给中小团队用，一边用定价把这批人推向更谨慎的立场。 T3developer.puter.com、eesel.ai（转引 Hacker News / LinkedIn）· 搜索命中

商业策略解读

许可证条款把免费商用的门槛设在“年营收 2000 万美元”和“月活 1 亿 / 月收入 2000 万美元”，这两个数字都是相当大的规模。这说明官方判断中小团队产生的商业威胁可以忽略，真正想防的是大厂或大型 MaaS 平台白嫖权重再转卖服务。同时第 4 条豁免了“通过 Moonshot 官方产品或认证推理伙伴访问”的场景，这意味着官方仍然希望大部分流量走它自己的 API 或授权伙伴通道，权重开放更多是拉开发者生态和技术声誉，不是把主要收入让出去。往后看，如果真有大厂踩到这两条门槛，Moonshot 大概率会走“定制商业协议”而非公开涨价，这也是这类条款惯常的落地方式。

官方承认的风险点

K3 技术博客里官方自己写了三条局限：思考历史必须完整回传给模型，否则输出会不稳定；模型在长周期任务里遇到模糊指令时容易自作主张、不按用户预期执行；整体用户体验和 Claude Fable 5、GPT 5.6 Sol 相比有明显差距。这类是厂商主动承认的，不是媒体挑刺，可信度更高。实际影响：第一条意味着接入 K3 的工具链必须严格遵守官方的多轮对话协议，随便截断上下文会导致效果变差；第二条对需要模型严格听指令、不能自由发挥的场景（比如合规、金融流程）是个减分项。 T1Kimi 官方技术博客 · 渲染抓取

下游落地信号

目前查到的是生态合作方而非终端企业客户：vLLM 官方发布了针对 K3 的部署配方（NVIDIA、AMD 硬件路径均有），Artificial Analysis 显示已有 5 家 API 服务商上架 K3（包括 EvoLink 等第三方平台，非 Moonshot 官方渠道）。搜索未查到具名的企业采用案例（如“某公司用 K3 替换了什么系统”），只查到面向 life sciences / 医疗等受监管行业的第三方分析文章在讨论“能不能”部署 K3，还没有实际部署的公开案例。这说明什么：K3 上线不到两周，目前的下游信号还停留在“推理服务商愿意接入”这一层，还没有看到终端企业公开宣布采用，这类信号通常需要几周到几个月才会出现，是接下来几天值得持续盯的点。 T3Artificial Analysis 服务商列表、EvoLink 官方博客、行业分析文章 · 搜索命中
