技术要点

官方技术博客今天已全文可读，这是昨天没有的。

  • 2.8T 参数，官方称是首个 3T 量级的开源模型；原生视觉，1M token 上下文；思考模式常开。 T1Kimi 官方技术博客 · 渲染抓取
  • MoE（混合专家，推理时只激活一部分参数）稀疏度：896 个专家里激活 16 个，配 Stable LatentMoE 框架。给了专家比例，但没给激活参数的绝对值。 T1Kimi 官方技术博客 · 渲染抓取
  • 两个架构件：KDA（Kimi Delta Attention，一种混合线性注意力）和 AttnRes（跨深度选择性取表征，而非逐层累加）。官方称整体扩展效率约为 K2 的 2.5 倍。 T1Kimi 开发者文档 · 渲染抓取
  • 训练侧：从 SFT 阶段起就做量化感知训练，权重 MXFP4、激活 MXFP8。部署建议 64 卡以上的超节点。 T1Kimi 官方技术博客 · 渲染抓取
  • 定价三档：缓存命中输入 $0.30 / 百万 token，未命中输入 $3.00，输出 $15.00。官方称编码场景缓存命中率超 90%。 T1Kimi 官方技术博客 · 渲染抓取
  • 官方自己承认整体性能仍落后 Claude Fable 5 和 GPT 5.6 Sol，并列了三条局限：思考历史必须完整回传否则输出不稳、任务中容易替用户做决定、用户体验与前两家有明显差距。厂商主动写局限，这段可信度相对高。 T1Kimi 官方技术博客 · 渲染抓取
  • Attention Residuals 的论文已挂在 Hugging Face papers（编号 2603.15031），但 K3 本身的技术报告仍说“随权重发布”。 T1Hugging Face moonshotai 组织页 · 渲染抓取

3Qwen已承诺

旗舰状态“已承诺”（无日期）。实际已开源的最新通用模型：Qwen3.6-35B-A3B（04-24）。简单说：Qwen 的旗舰线已经连续两代闭源——3.7-Max 和 3.8-Max 都只给 API，权重一个都没放。3.8 官方只承诺“开放权重”且没给日期，官方自己的研究页连这个条目都没有。

Qwen3.8-Max-Preview

  • 07-19 在上海世界人工智能大会预览，2.4T 参数，稀疏 MoE，多模态。无日期、无 model card、无完整跑分表、无第三方独立评测。 T3felloai、explainx、yottalabs、eesel 等媒体 · 07-18 至 07-20 · 搜索命中
  • “已承诺”的官方原文（已核）：承诺主体是 Qwen 官方 X 账号 @Alibaba_Qwen，07-19 发帖，原话 “Qwen3.8 is launching and going open-weight soon!”（Qwen3.8 即将发布，并将很快开放权重）。同帖还写了 2.4T 参数、“仅次于 Fable 5”、Qwen3.8-Max-Preview 已在 Alibaba Token Plan / Qoder / QoderWork 上线，并给了国际站与国内站两个 Token Plan 定价链接。全帖只有 “soon” 一个词，没有日期，没有许可证，没有仓库地址。 T1Qwen 官方 X 原帖 · 2026-07-19 · 截图核对
  • 官方用的词是 open-weight（开放权重），不是 open-source（开源）。这两个词的差别是实质性的：开放权重只表示权重文件可下载，不含训练代码、数据配方和技术报告，也不代表许可证宽松。因此本篇对 Qwen3.8 的表述统一为“开放权重”，不写“开源”。真正的许可条款要等 model card 和 LICENSE 出来才能判。 T1Qwen 官方 X 原帖 · 截图核对
  • 官方原帖的表述与四家媒体的转述完全一致，媒体没有加工。 T3dataconomy、aireiter、siliconangle、fonearena · 07-19 至 07-20 · 搜索命中
  • “仅次于 Fable 5”是官方原帖里的自我表述（原文 “second only to Fable 5”），同帖未附任何 benchmark 数据，也无第三方独立评测可交叉验证。 T1Qwen 官方 X 原帖 · 截图核对 T3siliconangle、digitalapplied · 搜索命中
  • 回一级信源核对的结果：Qwen 官方研究页里没有 Qwen3.8 任何条目，最新一条是 07-21 的 Qwen-Image-3.0（官方标签 Release）；Hugging Face 的 Qwen 组织页 458 个模型里也没有 Qwen3.8 仓库。官方 X 说了“即将开放权重”，但自有的研究页和模型仓库零落地痕迹。 T1Qwen 官方研究页 · 渲染抓取 T1Hugging Face Qwen 组织页 · 渲染抓取
  • 连续两代旗舰闭源，这是判断承诺可信度的关键背景：Qwen3.7-Max（2026-05 发布）和 Qwen3.8-Max（07-19 预览）至今都只有 API，Hugging Face 458 个仓库、ModelScope 460 个仓库里都找不到这两代的任何权重。Max 系列历来如此，所以 3.8 这次的“开放权重”属于路线转向而非延续惯例，可信度要打折。 T1Hugging Face 与 ModelScope 的 Qwen 组织页 · 渲染抓取 T3dataconomy · 07-20 · 搜索命中
